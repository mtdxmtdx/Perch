# 桌面感知手动测试矩阵（M1–M4）

在**隔离实例**里测：临时数据目录 + 模拟/自备模型服务，**不要动真实配置**。  
推荐从叠栈顶分支 `feat/m4-wrapup`（含 M1–M4）在 Windows 10/11 x64 上一次性跑完。

默认：所有新开关关闭时，除「在看 / 通话」信号与白名单提醒外，行为应接近 `1599deb`。

## 准备

1. `pnpm install && pnpm tauri dev`（或安装包；确认安装目录旁有 `THIRD_PARTY_NOTICES.md`）
2. 配好对话 / 辅助 /（可选）视觉模型；API Key 用测试号
3. 托盘 → 设置 → 陪伴 / 桌面感知：按下列用例逐项打开

| # | 步骤 | 期望 |

## M2 按需看屏

| # | 步骤 | 期望 |
| --- | --- | --- |
| M2-1 | 未授权时聊天说「看看屏幕」 | 工具列表无 `see_screen` / 调用被拒 |

## 性能抽样（开发机）

在 Linux 纯逻辑测试箱或 `cargo test` 中跑 `perf_sample_*`（`awareness/cuts.rs`、`awareness/capture.rs`）：

| 项目 | 本环境抽样（2026-11-02，Linux box） | 测试断言上限 |
| --- | --- | --- |
| `score_pair`（64×36 HSV） | ≈28 µs/次（200 次累计 ≈5.7 ms） | < 50 ms/次 |
| `downscale_area_average` 1920×1080→1280×720 | ≈153 ms | < 500 ms |

Windows 真机可再记一笔：单次 WGC 窗口捕获端到端耗时（含编码），仅作参考、不设门槛。
