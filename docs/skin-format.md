# Perch 皮肤格式（精灵图规格）

给美术和做皮肤的人看。Perch 的皮肤兼容 Codex 宠物格式：一个文件夹，里面一张精灵图（图集）加一个 `pet.json`。

配套模板：[`skin-template.png`](skin-template.png)（1536×1872，透明底，标好了格子、脚底基线、中线、安全边距和每行用途）。在它上面新建图层画，导出前删掉模板图层。

## 文件结构

```
<皮肤文件夹>/
├─ pet.json
├─ spritesheet.png      图集，PNG 或 WebP 都行（文件名由 pet.json 指定）
└─ skin.json            可选，改动画映射时才需要
```

`pet.json` 示例：

```json
{
  "id": "perch-bird",
  "displayName": "栖栖",
  "description": "Perch 的默认形象：一只停在窗沿上的蓝白小鸟。",
  "spritesheetPath": "spritesheet.png"
}
```

| 字段 | 说明 |
|---|---|
| `displayName` | 托盘「皮肤」菜单里显示的名字；不写就用文件夹名 |
| `spritesheetPath` | 图集路径，相对皮肤文件夹，不能指向文件夹外面；不写默认 `spritesheet.webp` |
| `spriteVersionNumber` | 可选。写 `2` 表示 11 行的图集（见文末「进阶」），不写就是 9 行 |
| `id`、`description` | Codex 用的字段，Perch 不读，照写即可 |

## 图集

- **8 列 × 9 行，每格 192×208 像素，整张 1536×1872。**
- 透明背景，RGBA。PNG 或无损 WebP 都行，不要有损压缩（边缘会出脏色）。
- 每行从第 0 列开始从左往右放帧，帧数不满 8 的行，后面的格子保持全透明。
- 程序按格子切图，所以每一帧都要完整地画在自己的格子里，不能跨格。

## 每一行画什么

帧时长由程序固定（单位毫秒），美术按这个节奏画就行。「Perch 里的用途」是程序实际在什么时候播这一行。

| 行 | Codex 名 | 帧数 | 每帧时长 | Perch 里的用途 | 小鸟建议 |
|---|---|---|---|---|---|
| 0 | idle | 6 | 280, 110, 110, 140, 140, 320 | **待机**，循环。平时站在任务栏或窗口顶边上的样子，出现得最多 | 站在窗沿上呼吸、眨眼、偶尔歪头 |
| 1 | running-right | 8 | 120 ×7，最后一帧 220 | **向右走**，循环 | 面朝右的小碎步或蹦跳 |
| 2 | running-left | 8 | 同上 | **向左走**，循环 | 面朝左。程序不会自动镜像，要单独画（可以直接把第 1 行水平翻转） |
| 3 | waving | 4 | 140, 140, 140, 280 | **被点击时打招呼**；**说话时**（回复正在出字）也循环播这一行 | 扇一下翅膀、张嘴叽叽 |
| 4 | jumping | 5 | 140 ×4，最后一帧 280 | 拆成单帧用，见下表 | 下蹲 → 起跳 → 空中 → 下落 → 落地 |
| 5 | failed | 8 | 140 ×7，最后一帧 240 | **agent 出错**：播一遍后**停在最后一帧** | 被吓到、羽毛炸开；最后一帧是能停住的"出错"姿势（比如蔫了、头顶冒烟） |
| 6 | waiting | 6 | 150 ×5，最后一帧 260 | 三处共用，速度不同：**等待授权**（原速）、**正在听你说话**（0.7 倍速）、**睡觉**（0.4 倍速） | 蹲坐、轻轻晃、偶尔看看你。要让它放慢以后也像在打盹 |
| 7 | running | 6 | 120 ×5，最后一帧 220 | **agent 工作中**，循环 | 忙碌：啄键盘、叼着东西跑来跑去 |
| 8 | review | 6 | 150 ×5，最后一帧 280 | **思考中**，循环（等模型回复、agent 在思考） | 歪头、翅膀托下巴、头顶冒问号 |

第 4 行（jumping）的单帧用法：

| 帧 | 用在 |
|---|---|
| 0 | 只在"完成"庆祝里出现（第 0～4 帧连播一遍）：起跳前的下蹲 |
| 1、2 | **起跳上升**：播帧 1 后停在帧 2；**被鼠标拖着时**也停在帧 2 |
| 3 | **下落** |
| 4 | **落地**；也是"完成"庆祝播完后停住的那一帧 |

所以第 4 行每一帧都要能单独成立。agent 完成任务时播第 0～4 帧，整行连起来要像一次开心的跳跃。

## 对齐要求（最重要）

程序根据第 0 行（idle）的画面自动推算脚在哪、身体中心在哪、头顶在哪，再拿这些位置去对齐任务栏、窗口边缘和对话气泡。所以：

1. **所有行的脚底都落在同一条基线上。** 程序把 idle 所有帧不透明像素的最低点当作脚底，贴在任务栏或窗口顶边上。其他行的脚比它高，切换动画时小鸟会悬空；比它低，就会陷进窗口里。模板里的红线（每格 y = 196，离底边 12px）就是建议的基线。
2. **小鸟在格子里水平居中，各行位置一致。** 程序取 idle 的水平中心当身体中心（模板里的蓝色虚线，x = 96）。走路时不要在格子里平移，位移由程序挪窗口完成，画原地踏步就行。
3. **跳跃、下落只画姿势，不要在格子里大幅上下移动。** 程序会真的把窗口抛起来、落下去，格子里再移动一遍会显得跳得忽高忽低。轻微的身体起伏没问题。
4. **idle 头顶上方不要放飘浮物。** idle 不透明区域的最高点是对话气泡小尾巴的位置，头顶飘着音符之类的东西，气泡会被顶高。其他行（比如思考的问号）可以有。
5. **不要画地面投影**，或者让投影非常淡（不透明度低于 15%）。否则投影会被当成脚底，小鸟就站高了。
6. 画面留在安全边距（四周 8px，模板里的绿色点线）以内。

## 透明度与鼠标点击

- 不透明度 ≥ 约 16%（alpha ≥ 40）的像素算"身体"：鼠标点得到、拖得动；更透明的地方鼠标会穿透到后面的窗口。判定精度是 4×4 像素一块。
- 避免大片半透明的光晕或特效，它们会让一大块看起来是空的区域也挡住鼠标。

## 尺寸与清晰度

- 托盘「大小」可以选 50% / 75% / 100% / 125% / 150%，**默认 75%，也就是一格显示为 144×156**，最小 96×104。
- 设计要在这么小的尺寸下也认得清：轮廓线粗一点、形状简单、少用细碎的线条（按 192×208 原尺寸画时，线宽不要细于 2px）。
- 风格和配色建议参考软件图标（`src-tauri/icons/source.png`）：扁平矢量风，深色描边，蓝灰色背羽、米白色肚子。

## 交付与自测

交付：`spritesheet.png`（1536×1872，RGBA）、`pet.json`，最好附上源文件（PSD、Aseprite 等）方便以后改。

自测：

1. 把皮肤文件夹放到 `%APPDATA%\Perch\skins\` 下面，比如 `%APPDATA%\Perch\skins\perch-bird\`。
2. 右键托盘图标 →「皮肤」里选它。
3. 检查以下几点：
   - 站在任务栏上不悬空、不陷进去。
   - 左右走路方向对。
   - 拖起来再松手，下落和落地衔接自然。
   - 点击后气泡的小尾巴正好指着头顶。
   - 透明区域能点到后面的窗口。

## 进阶：skin.json 和 11 行图集

想给某个状态换一行或换几帧，可以在皮肤文件夹里放 `skin.json`，按状态名覆盖默认映射：

```json
{
  "animations": {
    "sleep": { "row": 9, "loop": true },
    "think": { "row": 8, "speed": 0.8 },
    "done":  { "row": 4, "frames": [0, 1, 2, 3, 4], "loop": false }
  }
}
```

- 每项可以写 `row`（第几行）、`frames`（用哪几帧）、`durations`（每帧毫秒数）、`loop`（是否循环）、`speed`（速度倍数）。没写的沿用默认。
- 状态名：`idle` `walk_right` `walk_left` `wave` `talk` `jump` `fall` `land` `drag` `sleep` `sit` `listen` `think` `working` `attention` `error` `done`。
- 默认是 9 行。如果想给"睡觉"单独画一行，可以做成 11 行的图集（1536×2288），在 `pet.json` 里写 `"spriteVersionNumber": 2`，把新动画画在第 9、10 行，再用 `skin.json` 指过去。第 9、10 行没指定时长的帧按每帧 150ms 播。
- Perch 的扩展 `rows`：在 `skin.json` 里写 `"rows": 12`（9～32 之间的整数）声明图集有几行，就能再往下多画几行，图集高度相应变成 208 × 行数。写了 `rows` 时按它算，不再看 `spriteVersionNumber`。Codex 不认这个字段，多出来的行在 Codex 里只是用不上。
- `"hitTest": "live"`：鼠标穿透改为每次换帧时从屏幕上的画面实时判定，而不是加载时给每帧预先算好。效果一样，一般不用写，主要用来测试运行时判定。
- `"renderer": "<名字>"`：不用精灵图集，改由渲染器插件来画（比如骨骼动画）。这时图集相关的规定都不适用，皮肤文件夹里放什么由插件决定，见 [renderer-plugin.md](renderer-plugin.md)。

### 坐在窗沿上（sit）

站在某个窗口的顶边时，桌宠偶尔会在边沿上坐一会儿（20～60 秒）。**只有 `skin.json` 里写了 `sit` 的皮肤才会坐**，没写的皮肤不受影响。

```json
{
  "rows": 12,
  "animations": {
    "sit": { "row": 11, "frames": [0, 1, 2, 3, 4, 5], "durations": [900, 900, 110, 110, 1100, 900], "loop": true }
  }
}
```

画法建议：

- 身体压低，肚子贴着脚底基线（y = 196），脚收起来。窗口顶边就在基线这里，基线以下是窗口外面，可以画尾巴、脚垂在边沿外。
- 基线以下最多还有 12px，别画出格子底边。
- 水平中心和 idle 一致（x = 96），否则坐下时会左右跳一下。
- 只用来循环，节奏可以慢一点：偶尔眨眼、歪头、晃尾巴。

## 默认皮肤「栖栖」

程序内置了一只蓝白小鸟「栖栖」，没选过皮肤时就用它，在皮肤菜单里排第一。

- 它是用代码画出来的：`tools/bird-skin/generate.mjs` 按图标的造型和配色画出小鸟的各个部件，用参数摆出每一帧，再渲染成图集。
  - 想改造型或动作，改这个脚本后运行 `pnpm skin:bird`，会重新生成 `src-tauri/resources/skins/perch-bird/` 下的三个文件，编译时打进程序。
- 用的是 12 行图集（`skin.json` 里 `"rows": 12`）：
  - 第 0～8 行按上面的规定。
  - 第 9 行是睡觉（把头埋起来），第 10 行是在听你说话，第 11 行是坐在窗沿上，通过 `skin.json` 映射。
- 想换成手绘版本，按本文档画好图集，替换这三个文件即可，程序不用改。
